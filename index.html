Who We Are

We're Damon Maher and Alec Mahini. This site is where we post the financial models we're building, mostly around regime detection, volatility structure, and market state classification.

We try to keep everything here interpretable enough that we could explain it to each other, or to anyone else, without hand waving.

Learn more

Hidden Markov Model

Our first project is a Hidden Markov Model built for market regime detection. It estimates which state the market is probably in, whether that's trending, mean reverting, or volatile, using probabilistic inference instead of a visual read on a chart.

The explanation page walks through the math, the intuition behind it, and how we implemented it.
